# 自定义头像

左侧栏最下面那个账号位，原本显示的是 DeepSeek 平台的登录头像（用微信登录时就是微信头像）。这个插件让你在这里换上自己的图 —— 想放二次元就放二次元，`设置 → 头像` 里随时能换回来。

## 怎么用

1. 打开 **设置**（点左下角头像，或按 `Ctrl+Alt+,`）。
2. 左侧导航里选 **头像**。
3. 点 **上传图片**，选一张 PNG / JPEG / WebP / GIF（12 MB 以内）。
4. 在弹出的圆形窗口里拖动图片调整位置，滚轮或滑块缩放。
5. 点 **保存**。左下角的头像立刻变。

同一页里还有 **换一张** 和 **恢复默认**（回到账号原来的头像）。

## 存在哪里

- 本机 Harness 存储：`$DSH_HOME/account-avatar/avatar.json`，由插件的 Host 半边通过 `GET/POST /account-avatar/api/state|avatar` 读写。换浏览器、换端口、清浏览器缓存都不会丢。
- 浏览器缓存：`localStorage['dsh.account-avatar.v1']`，用来在页面首帧就显示自定义头像，避免闪一下原头像；Host 通道不可用时也靠它兜底。

存下来的图是 256×256 的 WebP（浏览器不支持 WebP 时用 PNG），通常 20–60 KB。图片只在本机处理，不上传任何服务器。

## 实现说明

- 账号菜单（设置、意见反馈、退出登录、通知、额度）**完全不动**，头像只是被一层样式盖住：插件的 Host 半边注册两条本机路由存图，浏览器半边在加载时把当前头像写成一条作用在 `[data-avatar-status]` 上的样式，原头像的 `img` 被隐藏、背景换成你的图。所以点开还是原来的菜单，登录状态、额度提醒都不受影响。
- 图片属于本机个人化设置，不写进会话记录，也不会同步到其他设备或平台账号。
- 如果某个版本的 DSH 改了账号菜单里头像元素的标记（目前是 `data-avatar-status`），替换会失效，届时需要更新这个插件；插件本身不会因此报错。
