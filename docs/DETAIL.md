# 自定义头像

左侧栏最下面那个账号位，原本显示的是 DeepSeek 平台的登录头像（用微信登录时就是微信头像）。这个插件让你在这里换上自己的图 —— 想放二次元就放二次元，`设置 → 头像` 里随时能换回来。

## 怎么用

1. 打开 **设置**（点左下角头像，或按 `Ctrl+Alt+,`）。
2. 左侧导航里选 **头像**。
3. 点 **上传图片**，选一张 PNG / JPEG / WebP / GIF（12 MB 以内）。
4. 在弹出的圆形窗口里拖动图片调整位置，滚轮或滑块缩放。
5. 点 **保存**。左下角的头像立刻变。

## 历史头像

每次保存都会进历史，最多留 **100 张**：

- 点历史里的任意一张，立刻切回它（当前那张带蓝色描边）。
- 鼠标移到缩略图上，右上角出现 **×**，点了删除。
- 存满 100 张后再存，会顶掉**最旧**的一张；当前正在使用的那张永远不会被顶掉。
- 删掉当前正在使用的那张时，自动退回到最新的一张；如果全删光，就回到账号头像。

## 头像形状

三个选项，全局生效，左下角头像和设置页预览同步变：

| 形状 | 圆角 |
|---|---|
| 圆形 | 50% |
| 圆角方形 | 26% |
| 方形 | 10% |

默认是圆形，跟原生一致。

## 存在哪里

- 本机 Harness 存储：`$DSH_HOME/account-avatar/avatars.json`，由插件的 Host 半边通过 `GET /account-avatar/api/state` 和 `POST /account-avatar/api/mutate` 读写。换浏览器、换端口、清浏览器缓存都不会丢。
- 浏览器缓存：`localStorage['dsh.account-avatar.v2']`（当前那张）和 `localStorage['dsh.account-avatar.shape.v2']`（形状），用来在页面首帧就画对，避免先闪一下账号头像。

每张图存两份：256×256 的原图（负责显示，通常 20–60 KB）和 96×96 的缩略图（负责历史列表，约 4 KB），这样列表不用把整库原图都拉下来。图片只在本机处理，不上传任何服务器。

旧版本存的单张 `avatar.json` 会在第一次读取时自动迁移成历史里的第一张，然后删掉旧文件。

## 实现说明

- 账号菜单（设置、意见反馈、退出登录、通知、额度）**完全不动**，头像只是被一层样式盖住：插件的 Host 半边注册两条本机路由存图，浏览器半边把当前头像和形状写成一条作用在头像位上的样式，原头像的 `img` 被隐藏、背景换成你的图。
- 头像位怎么定位：优先用原生标记 `[data-avatar-status]`；从没设过头像的账号原生不渲染这个标记（回调的是灰色人像图标），这时插件自己给头像位打一个 `data-ast-avatar` 标记再上样式，所以空头像的账号一样生效。
- 图片属于本机个人化设置，不写进会话记录，也不会同步到其他设备或平台账号。
- 如果某个版本的 DSH 改了账号菜单的结构（菜单按钮不再带 `aria-haspopup`，或头像位不再是「带图标的方形 span」），自定义标记就打不上，替换会失效，届时需要更新这个插件；插件本身不会因此报错。
